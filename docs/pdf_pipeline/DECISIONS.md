## 2026-10-07 — умовні позначення і єдина шкала складності
Джерела: Мерзляк стор. 4 («Умовні позначення»), Тарасенкова стор. 3 («Дорогі учні!»).

| Рівень (код) | Мерзляк-5 | Тарасенкова-6 |
|---|---|---|
| `preparatory` — підготовчий | — | `35′.` штрих |
| `medium` — початковий/середній | `3.◦` кружечок | `40°.` кружечок |
| `sufficient` — достатній | `8.•` одна крапка | без значка |
| `high` — високий | `11.••` дві крапки | `72*.` зірочка |
| `olympiad` — гуртки/факультатив | `25.*` зірочка | — |
| не вказано | без значка (вправи для повторення) | — |

- Мерзляк: значок **після** крапки; номер, надрукований **кольором** (зелений `10.•`) — домашнє завдання; `◀` — кінець прикладу.
- Тарасенкова: значок **перед** крапкою; домашнє — іконка-будиночок на полі.
- Однаковий значок означає різне в різних книгах (`*`!) — тому значки живуть у профілях, а в БД пишемо єдиний код рівня.
- OCR читає `•` як `"`, `••` як `""` — профіль приймає й ці варіанти, але такі вправи варто перевіряти.

## 2026-10-06 — назви модулів не збігаються зі стандартною бібліотекою
`types.py` → `datatypes.py`, у майбутньому `inspect.py` → `pdf_inspect.py`.
Чому: якщо запустити файл з папки `pdf_pipeline/` напряму, наш `types.py`
підмінив би стандартний модуль `types`, і зламався б увесь Python
(dataclasses, typing). Запускаємо модулі через `python -m ...`.

## 2026-10-06 — препроцесинг: шумозаглушення ДО збільшення
Пресети: `default` (×2) для звичайних сторінок, `lowres` (×3) для <120 ppi.
`denoise` стоїть перед `upscale`: на стор. 10 Тарасенкової 8.5 с → 2.5 с
на сторінку (у 4–9 разів менше пікселів). Бінаризацію в пресети поки
не додаємо — Tesseract робить свою; порівняємо цифрами у фазі 5.

## 2026-10-06 — OCR за замовчуванням: пресет default + psm 4 + ukr+eng
Бенчмарк на стор. 7 Мерзляка (BENCH.md): default_psm4 — CER 0.028,
default_psm6 — 0.033, без препроцесингу — 0.039, лише `ukr` — 0.053

Швидкість у VM ~50 с/стор. — для 305 сторінок знадобиться `--workers` (фаза 17).

## 2026-10-06 — golden без колонтитула; бенчмарк рахує лише текст тіла
Golden стор. 7 тепер без рядка колонтитула (як і хотіли: назва колонтитула
зберігається окремо, раз на документ). `bench.page_text` бере `body_lines`

з нормалізацією — **0.027**. Залишок — переважно математика (`·`, `18 і 81`).

## 2026-10-06 — .env для команд у терміналі
`python -m education.pdf_pipeline.…` не читав .env, тому на Windows бенчмарк
пішов зі стандартними (fast) моделями: «tesseract-5.5.3-default», 3.9 с/стор.,
CER 0.024 (зі старим golden). Тепер CLI використовують
`PipelineConfig.from_env_file()`. Перезапустити бенчмарк з best-моделями і
порівняти швидкість/якість best vs fast.

## 2026-10-06 — нормалізація: «-» між числами не замінюємо
На стор. 7 OCR послідовно дає «—» для справжнього мінуса і «-» для зламаного
множення «·». Довге тире між числами → «−», короткий дефіс лише позначається
`suspect_operator` (перевірить vision-етап). Апостроф зводимо до ASCII «'».

## 2026-10-07 — зсув номерів сторінок змінюється всередині книги
Тарасенкова: на початку друкований номер = номер PDF (стор. 13 = 13), у кінці зсув 9
(відповіді: 287 = PDF 296). `infer_book_pages` тепер голосує у вікні ±8 сторінок,
а не по всій книзі. Старе твердження в `data/tarasenkova_toc_pages.py`
(`PRINTED_TO_PDF_PAGE_OFFSET = 9` для всієї книги) — неправильне для початку.
