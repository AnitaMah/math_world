# Рішення (DECISIONS)

## 2026-10-03 — db.sqlite3 не зберігаємо в git
Чому: база змінюється при кожному імпорті, бінарний файл засмічує історію,
дані відтворюються командами імпорту.

## 2026-10-03 — новий SECRET_KEY
Чому: старий потрапив у git у файлі .evn. Тепер ключ лише в .env (у .gitignore).

## 2026-10-06 — Python 3.xx, віртуальне середовище .venv
Чому: потрібен Python ≥ 3.10 (синтаксис `X | None`).

## 2026-10-06 — залежності розділено на 4 файли
- requirements.txt — сайт (Django, decouple, Pillow)
- requirements-pipeline.txt — розпізнавання PDF
- requirements-gemini.txt — Gemini (необов'язково)
