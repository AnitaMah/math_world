# Фікстури для тестів pdf_pipeline

Тут лежать маленькі реальні дані для тестів: картинки окремих сторінок
підручників (`*.png`) і ручні точні транскрипції цих сторінок (`golden/*.txt`).
Транскрипції пишемо з картинки, а не з OCR — це «правильна відповідь»,
з якою порівнюємо результат розпізнавання.
