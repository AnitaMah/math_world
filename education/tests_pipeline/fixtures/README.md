# Фікстури для тестів pdf_pipeline

Тут лежать маленькі реальні дані для тестів: картинки окремих сторінок
підручників (`*.png`) і ручні точні транскрипції цих сторінок (`golden/*.txt`).
Транскрипції пишемо з картинки, а не з OCR — це «правильна відповідь»,
з якою порівнюємо результат розпізнавання.

## golden/ — правила транскрипції
- Текст переписується з **картинки**, не з OCR. Список сторінок — `golden/golden.json`.
- Абзац пишемо одним рядком; перенесені слова — цілими (`натуральних`, не `натураль-них`).
- Маркери складності: `•`, `••`; множення — `·`; мінус — `−`; тире — `—`; апостроф — `’`.
  (Для CER вони нормалізуються, але в golden пишемо як у книзі.)
- Вміст рисунків (числа в таблиці тощо) **не** переписуємо, лише підпис `Рис. 1`.
- Колонтитул і номер сторінки переписуємо — OCR їх теж бачить.
- Сітку підпунктів `1) … 4) … 7)` пишемо по рядках, як вони надруковані.
