# Моки API (фаза 6 плану фронтенду)

Моки повторюють **контракт із бекендом** (`docs/frontend/DECISIONS.md` і документ
«План: переписати фронтенд…», розділ «Контракт з бекендом»).
**Змінюєш контракт — міняєш і моки** (і навпаки), інакше фронтенд і бекенд розійдуться.

| Файл | Замість | Що всередині |
| --- | --- | --- |
| `me.guest.json` / `me.user.json` / `me.teacher.json` | `GET /api/me/` | гість / залогінений гравець / вчитель (`is_teacher: true`) |
| `grades.json` | `GET /api/grades/` | 5 і 6 клас для екрана «Світ» |
| `grade-5.json` | `GET /api/grades/5/map/` | **реальний стан БД**: вправи лише в уроках 1–6; 1–3 пройдено, 4 поточний, 5–6 закриті, решта «у хмарах» |
| `grade-5.demo.json` | те саме | «багато зірок»: 1–9 пройдено, 10 поточний, 11–38 закриті |
| `grade-5.states.json` | те саме | усі 5 станів у кожному параграфі (кілька `current` — навмисно, для знімків) |
| `grade-6.json` | `GET /api/grades/6/map/` | Тарасенкова: урок = §, поля уроку на параграфі, `items: []`, усе «у хмарах» |

Назви й id — справжні з `db.sqlite3`; прогрес гравця — вигаданий. У `demo` і `states` урокам 7–38
(їх вправ ще немає в БД) дано умовні 12 + 2 завдання — інакше «пройдений урок без завдань» суперечив би контракту.
Перегенерувати: `python tools/frontend/make_mocks.py`. Перевірити: `python tools/frontend/check_mocks.py`
(те саме запускають тести Django).

У браузері: `?mock=1` (реальний стан), `?mock=demo`, `?mock=states`; `?mock_user=1` — залогінений,
`?mock_user=teacher` — вчитель (показує перемикач «Режим вчителя» у топбарі, фаза 20, FE-0645).

## Режим вчителя (фаза 20, беклог FE-0645)

`class_pct` на вузлі (`grade-*.json`) — % учнів класу зі зіркою на цьому уроці; `null`, якщо
завдань ще немає (`soon`). Контракт з бекендом (FE-0640 — модель класу + сам ендпоінт) ще не
зафіксовано (`docs/frontend/DECISIONS.md`, 2026-10-28) — ці числа вигадані формулою в
`make_mocks.py`, лише щоб верстати перемикач і бейдж на вузлах; форма відповіді може змінитись,
коли Partner B здасть контракт.

## Гра (фаза 14)

- `play.json` — відповідь `/api/play/items/<id>/`: 3 авто-завдання (одне вже розв’язане) і одне ШІ.
  Поле `_mock_answers` (`{id підпункту: відповідь}`) — **лише для моків**, справжній API відповідей не віддає.
  Правильні: 13, 81, 6; ШІ-задача — розв’язок, де є 16 і 9.
- `play.empty.json` — урок без ігрових завдань (`?mock=1&mock_play=empty`).
- `?mock_ai=off` — перевірка ШІ відповідає 503 `ai_unavailable`.
